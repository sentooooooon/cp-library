cp-library 早見表

問題に合うものを探して、コピーして、貼るだけ。

使い方

  1. 下の一覧か検索で、問題に合うものを選ぶ。「いつ使う？」と例題を見て決める。
  2. 「例ごとコピー」を押してエディタに貼る。そのまま動くプログラムなので、main の中だけ問題に合わせて書き換える。
  3. もう自分のコードがあるときは「ライブラリだけコピー」を押して、黄色いところ（using namespace std; と int main() の間）に貼る。
  4. 入力が 1 始まりなら、読んだあとに -1 して 0 始まりにする。どの例にも書き方が入っている。
番号は 0 始まり 区間 (l, r) は r を含まない 数の配列は vector<long long> 行けない・ないときは -1 2 つ以上使うときは続けて貼る
